# Claim Boundaries

## What is measured

The testbed measures how a simulated platform profile changes when a fixed or
controlled shopping-agent trace is interpreted under different provenance and
profile-update contracts.

The registered primary outcomes are:

1. future recommendation regret;
2. profile contamination;
3. current task utility.

## What is not measured

There are no human participants. The project does not measure trust, perceived
control, satisfaction, identity, authorship, willingness to use, or any other
human-experience outcome.

The title *The Agent Became Me* is a provocation about attribution. In methods,
data, charts, and result statements, the project uses the narrower terms
`inferred profile`, `preference representation`, and `profile contamination`.

## Required language

Use:

- “In this synthetic testbed…”
- “The simulated updater assigned…”
- “Across the registered configurations…”
- “This result motivates subsequent human evaluation.”

Do not use:

- “Users felt…”
- “The interface builds trust.”
- “The design protects identity.”
- “Platforms currently infer this trait” without separate evidence.
- “The agent believed…”

Every visible result must expose its scenario count, run count, protocol version,
and whether it is observed in generated output or merely an expected outcome.
